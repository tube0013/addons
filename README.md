# Zigpy apps

Home Assistant app repository for the [zigpy](https://github.com/zigpy) project.

## Installation

Add this repository to your Home Assistant app store:

[![Open your Home Assistant instance and show the add app repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fzigpy%2Fzigpy-addons)

## Apps

- **[Ziggurat](./ziggurat)** - an experimental host-side Zigbee stack written in Rust. Turns any OpenThread RCP radio into a Zigbee coordinator.
